## How project AIs should use these notes

1. Read the note before using the source as project context.
2. Follow its source link to inspect the original video and caption track whenever exact wording, a speaker attribution, or a timestamp matters. The captions are the accessible transcript; this repository intentionally stores a structured summary and analysis, not a full verbatim transcript.
3. Label source statements, interpretation, and independent evidence separately. Treat the speaker's claims as claims by the speaker.
4. Do not promote spiritual/philosophical frameworks into scientific laws, diagnoses, causal claims, or project requirements without independent evidence.
5. Cite timestamps from the source when discussing specific moments. Confirm the wording in the captions because automatic captions can be wrong.

## Adding another selected video

Create a note named `<youtube-video-id>-<short-topic>.md` containing:

- original title, link, creator/speaker and language;
- transcript/caption type and retrieval date;
- a concise synopsis and timestamped topic map;
- detailed concepts and arguments, clearly attributed;
- analysis of assumptions, uncertainty, counterexamples and relevant project application;
- safety/evidence boundaries for medical, legal, financial or other high-stakes claims;
- a link to the original source for transcript access.

Use paraphrase and limited quotation; do not mirror a full copyrighted transcript into the repository. Add a bullet to this index after verifying the note and link.

## Scope

This is a learning archive, not a statement of NOVA's implementation or product behavior. A video may suggest hypotheses or useful vocabulary; project code and independent evidence remain authoritative for technical claims.
